# Fouad & Hala — A Moment for a Lifetime

Repository: `fouad-hala-lifetime`

GitHub Pages (on horowstudio-oss):
`https://horowstudio-oss.github.io/fouad-hala-lifetime/`

## Upload
Upload the CONTENTS of this folder to the repository root. Then Settings → Pages → Deploy from a branch → main → /(root).

## Edit later
Edit `config.js` only for names, date, venue, copy, timeline and dress code.

## Media
All images are local under `assets/` and referenced by the page. The exact uploaded wedding music is included as `assets/wedding-music.mp3` and begins after the wax-seal interaction.
